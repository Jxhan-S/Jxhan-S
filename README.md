## 🚀 Sobre mí

- 💻 Desarrollador **web full-stack**, construyendo proyectos tanto de frontend como de backend
- 🎓 Estudiante de programación, aprendiendo y mejorando con cada proyecto nuevo
- 🎮 Interesado en el desarrollo de videojuegos, principalmente con **Godot**
- 🐧 Muy cómodo en entornos **Linux** (Ubuntu, Arch, Fedora), tanto para desarrollo como para administración de sistemas
- 🌐 Me gusta desplegar y mantener mis propios **servidores**, usando **Docker**, **CI/CD** y redes privadas con **Tailscale**
- 🔐 Interesado en la parte de redes y seguridad: exposición controlada de servicios, proxys inversos y acceso remoto
- 📫 ¿Hablamos? Escríbeme por GitHub o abre un issue en cualquiera de mis repos

## 🐧 Linux & Sysadmin

- 🖥️ Uso diario de **Linux** como entorno principal de trabajo, no solo como sistema secundario
- ⚙️ Cómodo en terminal: gestión de paquetes (`apt`, `pacman`, `dnf`), permisos, procesos y servicios con `systemd`
- 🔄 Me gusta entender cómo funciona el sistema por dentro, no solo usarlo desde la superficie
- 🧩 Alternando entre **Ubuntu**, **Arch** y **Fedora** según el proyecto o lo que quiera experimentar en cada momento

<br/>

## 🌐 Despliegue y redes

- 🚀 Despliegue de **aplicaciones web** y **servidores** propios desde cero
- 🔗 Uso de **Tailscale** para crear redes privadas (VPN mesh) entre mis dispositivos y servidores
- 🌍 Exposición de servicios locales a internet de forma controlada mediante **Funnels** de Tailscale
- 🐳 Contenedores con **Docker** para levantar servicios de forma aislada y reproducible
- 🔧 Configuración de **NGINX** como proxy inverso para ordenar el tráfico entre varios servicios
- 🔁 Integración de pipelines de **CI/CD** para automatizar pruebas y despliegues
- 📡 Nociones sólidas de redes: DNS, puertos, firewalls y acceso remoto seguro
